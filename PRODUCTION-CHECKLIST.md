# Production Checklist

- Connect a Sri Lankan payment gateway and define deposit settlement rules.
- Build product inventory and pre-order status management.
- Add an admin panel for prices, sizing, delivery timelines and drop badges.
- Connect WhatsApp Business with pre-filled product and size messages.
- Add email/SMS order confirmation and status updates.
- Publish authenticity, pre-order, delivery, return, privacy and terms pages.
- Compress production images to AVIF/WebP and add responsive image sizes.
- Add Google Analytics, Meta Pixel and TikTok Pixel only after consent setup.
- Add Product, Organization and Breadcrumb structured data.
- Test on current iPhone Safari and common Android Chrome devices.
- Run accessibility, performance and checkout usability testing.
